# Local typography

DM Sans, Manrope, and Playfair Display are hosted locally. Files were downloaded from Google Fonts. Their SIL Open Font Licenses are included in this directory.

- DM Sans: https://github.com/google/fonts/tree/main/ofl/dmsans
- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope
- Playfair Display: https://github.com/google/fonts/tree/main/ofl/playfairdisplay
